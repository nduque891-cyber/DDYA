Diseños de Datos y Algoritmos (DDYA)

Bienvenido al repositorio de la asignatura Diseños de Datos y Algoritmos. Este espacio contiene las clases prácticas y laboratorios desarrollados durante el curso, enfocados en el estudio, análisis de complejidad e implementación de estructuras de datos y algoritmos en Python.

Estructura de las Clases Prácticas:

El repositorio contiene los laboratorios semanales del curso:

Clases Prácticas de Estructuras Lineales y Análisis:
Desarrollo de ejercicios sobre análisis de complejidad (Notación Big O) e implementación de estructuras de datos lineales como listas, pilas y colas.

Clases Prácticas de Ordenamiento y Búsqueda:
Implementación de algoritmos de búsqueda y métodos de ordenamiento iterativos y recursivos.

Clase Práctica de Árboles y Estructuras Jerárquicas (Semana 08):

Árbol Binario de Búsqueda (BST): Operaciones de inserción ordenada y búsqueda de elementos.

Árbol Auto-balanceado (AVL): Factor de balance e implementación de rotaciones simples (LL, RR) y dobles (LR, RL).

Recorridos Recursivos: Algoritmos de recorrido Preorden, Inorden y Postorden.

Visualización Gráfica: Representación jerárquica de la estructura del árbol usando NetworkX y Matplotlib.

Clases Prácticas Adicionales:
Laboratorios complementarios sobre algoritmos de optimización, grafos y resolución de problemas estructurados.

Tecnologías Utilizadas:

Lenguaje: Python 3

Entornos: Jupyter Notebook, Visual Studio Code, Google Colab

Librerías: NetworkX, Matplotlib, NumPy

Instrucciones de Uso:

Clonar este repositorio en tu equipo:
git clone https://github.com/nduque891-cyber/DDYA.git

Entrar a la carpeta del repositorio:
cd DDYA

Instalar las librerías necesarias:
pip install networkx matplotlib numpy

Abrir los cuadernos de cada clase práctica en Jupyter Notebook o Google Colab.
